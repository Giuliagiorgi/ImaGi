2. Analysis settings

CLIP image embeddings run locally using Transformers.js. The first run downloads the model from Hugging Face; later runs may reuse the browser cache. Internet is required initially.

Difference from ImaGi desktop: this version currently uses CLIP only (not ResNet18), and DBSCAN instead of HDBSCAN. PCA/UMAP and DBSCAN implementations are browser-native, so numerical results can differ. No artificial image-count limit; speed and memory depend on your computer.
